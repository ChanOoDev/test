# /feature <issue-number>

Workflow:
1. Read complete issue.
2. Read parent epic and dependencies.
3. Load relevant rules/docs/source.
4. Create short implementation plan.
5. Implement only the issue scope.
6. Add/update tests.
7. Run lint/typecheck/tests/build where relevant.
8. Self-review.
9. Prepare PR summary.

Stop and report if blocked by unresolved dependency or architecture conflict.
