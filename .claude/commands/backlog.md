# /backlog <prd-path-or-requirement>

Workflow:
1. Read PRD/requirement.
2. Load relevant architecture and existing backlog context.
3. Product Owner: capabilities, epics, stories.
4. Business Analyst: clarify rules and acceptance criteria.
5. Architect: add technical constraints and risks.
6. Scrum Master: validate size, dependencies, readiness.
7. Produce proposed backlog only.

Output:
## Capability Analysis
## Proposed Epics
## Stories
## Dependency Graph
## Implementation Order
## Existing Issue Mapping
## Risks / Assumptions

Do not create GitHub issues.
