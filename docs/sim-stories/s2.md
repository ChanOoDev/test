## Story
As a receptionist,
I want to view all appointments for a chosen day,
so that I can run the clinic schedule.

## Context
Read-side vertical slice reusing E1-S1 schema and RBAC.

## Functional Requirements
- Filter by day (required); optional doctor and status filters.
- Role scope: receptionist/admin see all; doctor sees own only.
- Sort by time; show patient, doctor, time, reason, status.

## Constraints
- RBAC enforced server-side; response must never leak others' appointments to a doctor (payload-level test).
- Server-side filtering, not client-side.

## Technical Impact
- GET query endpoint + query model.
- React list view, filters, loading/error states.

## Acceptance Criteria
- [ ] Day query returns all appointments for receptionist/admin.
- [ ] Doctor query returns only own appointments.
- [ ] Doctor cannot read another doctor's appointment data (payload-level assertion in tests).
- [ ] Optional doctor/status filters applied server-side.
- [ ] Empty day returns 200 empty list.

## Testing
Unit: query filters, role scoping. Integration: RBAC read-scope leak test. Frontend: filters, empty state.

## Assumptions (from epic)
- A1 slot model, R2 timezone — see epic body.
