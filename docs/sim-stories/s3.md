## Story
As a receptionist,
I want to reschedule or cancel an appointment,
so that the schedule stays accurate when plans change.

## Context
Update/cancel slice reusing E1-S1 schema and conflict guard.

## Functional Requirements
- Reschedule: change date/time; re-run double-booking check; conflict → 409.
- Cancel: status → `cancelled`, reason recorded; cancelled excluded from active day view.
- Only `scheduled` (and `checked_in` per assumption A4) appointments reschedulable/cancellable.
- Optimistic concurrency: stale version update rejected (409).
- Authorization: receptionist/admin; doctor cannot modify own (403). No deletion — cancellation is a status transition (audit trail).

## Technical Impact
- PATCH/PUT update command, row version for concurrency.
- React reschedule form + cancel dialog with reason.

## Acceptance Criteria
- [ ] Reschedule to free slot → 200, new date persisted.
- [ ] Reschedule to conflicting slot → 409.
- [ ] Cancel → status `cancelled`, reason stored, excluded from active views.
- [ ] Cancel already-`completed` appointment → 422.
- [ ] Concurrent edit on same appointment → 409, no lost update.
- [ ] Doctor attempting reschedule → 403.

## Testing
Unit: transition preconditions, concurrency. Integration: conflict on reschedule, audit. Frontend: cancel flow.

## Assumptions (from epic)
- A1 slot model, A4 checked_in cancellable, A5 cancel reason optional — see epic body.
